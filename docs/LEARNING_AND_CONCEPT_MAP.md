| # | Objective | Where demonstrated |
|---|-----------|-------------------|
| 1 | Define burning/combustion as oxygen + substance → heat + light | Science chapter; source definition |

| 4 | Predict sealed-jar outcome before observing | Prediction chapter |

# Scientific Concept Map

```
Air (invisible)
  └── contains oxygen (needed for burning)
        └──
Fuel/substance + Oxygen + Heat  →  Combustion  →  Heat + Light

Closed system (lid on, no gaps)
  → air used up → burning stops

Bottom gap only + lid on
  → incomplete renewal → flame goes out (slightly longer)

Bottom gap + top open
  → fresh air in + warm air out → air renewed → burning continues
```
